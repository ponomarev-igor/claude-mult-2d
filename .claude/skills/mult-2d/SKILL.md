# Мультик из озвучки (mult-2d)

Работает только внутри этой папки (скилл проектный, лежит в `.claude/skills/`). Все пути ниже от корня папки.

На входе: файл озвучки (mp3/wav/m4a) в `in/`. На выходе: `projects/<имя>/render.mp4`, 1920×1080, 30 к/с.

## Что нужно на компьютере

- Node.js 22+ и ffmpeg (`node -v`, `ffmpeg -version`). Если нет, скажи человеку поставить: Mac `brew install node ffmpeg`, Windows `winget install OpenJS.NodeJS ffmpeg`.
- Python 3.9+.
- Первый запуск сам скачает HyperFrames и модель распознавания речи (несколько минут, один раз).

## Порядок работы

1. **Проект.** Спроси имя латиницей, если не дали. Запусти:
   `python3 .claude/skills/mult-2d/lib/new_project.py in/<файл> projects/<имя> --lang ru`
   Появятся `projects/<имя>/assets/audio/vo.wav` и `transcript.json` (слова с таймингами). Язык другой: `--lang en` и т.д.
2. **Прочитай расшифровку** целиком. Исправь в ней явные ошибки распознавания (имена, термины), они попадут в субтитры.
3. **Раскадровка.** Разбей текст на сцены по смыслу, 3–9 секунд каждая, граница сцены на начале фразы. На каждую сцену реши: где действие, кто в кадре, что делают, какие 1–3 слова голоса подсветить. Покажи человеку таблицу сцен (время, что в кадре) и дождись ок. Это главная творческая часть, не пропускай.
4. **Сцены.** Создай `projects/<имя>/scenes.py` по образцу `.claude/skills/mult-2d/examples/ekhnaton.py`. Библиотека `lib/mult.py`, в ней докстринги. Время в JS пиши в секундах всего ролика, бери из `transcript.json` (или `p.t("слово")`).
5. **Сборка и проверка.**
   `python3 projects/<имя>/scenes.py` → затем в папке проекта `npx --yes hyperframes@0.9.45 check`
   Ошибки исправь. Сними кадры: `npx --yes hyperframes@0.9.45 snapshot --at 2,8,15 --no-end -o snaps` и посмотри их глазами: персонажи не перекрывают подписи, текст читается, никто не обрезан.
6. **Рендер** после ок человека: в папке проекта `npx --yes hyperframes@0.9.45 render -o render.mp4` (45 секунд ролика рендерятся примерно за минуту).

## Библиотека: что есть

```python
from mult import *
p = Project("projects/имя")            # читает transcript.json, длина = конец последнего слова + 0.6 с
p.scene("s1", start, dur, body, js, ambient=True, birds=0)
p.sfx("pop", [1.2, 3.4]); p.build()
```

**Персонаж** `char(id, kind, skin, h, x, bottom, flip, tool, outfit, pants, hair)`:
- `kind`: `man`, `woman`, `worker`, `pharaoh`, `queen`, `girl`. Ребёнок = любой kind с маленьким `h`.
- `skin` a–f, `outfit` цвет одежды, `hair` dark/brown/blond/red/gray, `tool="hammer"`.
- Крупный план: `h` 600–760, `bottom` 1000–1080. Общий: `h` 380–520, `bottom` 860–960. Пол сцены на y=800.

**Действия в js** (время = секунды всего ролика):
- `idle(id, from, to)` дыхание + покачивание головы + моргание. Ставь КАЖДОМУ персонажу в кадре на всю сцену, иначе он мёртвый.
- `face(id, рот, брови, t)`: рот `n` спокойный, `s` улыбка, `o` открытый, `f` грустный; брови `n`, `a` злые, `u` поднятые.
- `arm(id, "L"|"R", угол, t)`: -150 рука вверх (правая), 150 левая вверх, 0 вниз. `wave(id, side, a, b, t, раз)` махать/бить.
- `talk(id, t, раз)`, `blink(id, t)`, `walk("#обёртка", [ids], dx, t, длительность)`.
- `pop(sel, t)` появление, `out(sel, t)`, `grow(sel, t)` вырасти снизу (дома), `drop(sel, t, i)` упасть сверху, `pulse(sel, t)`, `shake(sel, t)`.

**Объекты:** `sky()`, `ground()`, `sun()`, `box()` для домов, стен, экранов, мебели (с контуром), `scroll()` подпись-свиток, `word()` крупное слово с обводкой, `glyphs()` египетский картуш.

## Правила стиля

- Каждый ключевой смысл голоса = что-то происходит в кадре в момент слова: слово выскакивает, персонаж реагирует лицом или рукой, предмет падает или растёт.
- Эмоции меняй по смыслу текста: приказ = злые брови, радость = улыбка, удивление = открытый рот.
- 1–2 крупных слова и максимум 1 свиток одновременно. Текст не ниже 30 px.
- Субтитры внизу (y ~935), персонажи могут заходить под них, но лица и подписи нет.
- НИКОГДА не делай плашки «тёмный прямоугольник с цветной полосой сбоку»: это примета ИИ-монтажа. Для подписей есть `scroll()` и `word()`.
- Звуки: `pop` на появления, `whoosh` на смену сцены, `click` на удары, `impact` на главный момент. Громкость 0.15–0.3, голос всегда громче.
- Камера: каждая сцена медленно наезжает сама (1.0 → 1.04). Резких зумов не добавляй.
